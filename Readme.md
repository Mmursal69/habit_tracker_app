# Habit Maker: The Routine Tracker
A lightweight, locally persistent single-page application for tracking weekly habits and building streaks.
## How to Run 
This project is built using only html,css, javascript. There is no installation required.
1. Clone or download this repo.
2. Open the project folder.
3. Double-click index.html to open it.
Or you can got to [here]{https://habit-tracker-app-roan.vercel.app/}
